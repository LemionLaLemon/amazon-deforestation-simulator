# Amazon Deforestation Simulator
**A complete accurate experience of deforesting the amazon rainforest**

<img width="852" height="495" alt="file8" src="https://github.com/user-attachments/assets/c6e5e02a-8b8f-4425-8ca0-72672cbd9372" />

Have you ever had the urge to deforest the amazon? Well now your wish is granted!!!

With amazon deforestation simulator you can do a total of:

- Walk around
- Chop trees down
- Sell trees

And you must do so while avoiding the legal consequences of chopping down trees that you don't own!!!

"Lawyers" will terminate your life if you fail to comply with their cease and desist orders, or you choose the politically correct option and just bribe them!

## SYSTEM REQUIREMENTS

OS - Linux (WSL untested but should function)

CPU - Strictly a x86-64 CPU, no ARM

MEMORY - Same as the calculator, if you can run linux you can run this

Terminal - Tested on kitty and tty, must be ANSI/xterm compatible

Terminal font - Must include the ♣ character

Locale - UTF-8 required



 ## THIS WILL NOT RUN ON:

macOS/Window

non x86 CPUs such as ARM

non utf-8 locales
